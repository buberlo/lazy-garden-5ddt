# Lazy Garden

> Lazy Garden: ai app but everything is temporary (24h TTL).

A one-month ai project called Lazy Garden — but everything is temporary (24h TTL). Built fast, shipped faster.

## Features
- Core ai loop that works in under 10 seconds of use
- The twist: but everything is temporary (24h TTL)
- Zero-setup onboarding — useful within one minute
- Share/export so friends can join or compete

## Stack
- ollama + SvelteKit
- SQLite
- TypeScript

## Getting started
```
npm create @sveltejs/kit@latest lazy-garden; cd lazy-garden; npm install; npm install better-sqlite3; ollama pull llama3.2:1b; npm run dev; open http://localhost:5173
```
